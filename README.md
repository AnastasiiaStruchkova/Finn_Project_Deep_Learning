# Finn_Project_Deep_Learning


# Прогнозування швидкості усиновлення тварин (Multimodal Deep Learning)

*Модель глибокого навчання для передбачення того, як швидко тварина з притулку знайде нову родину, на основі аналізу фотографій та текстових описів.*

## Огляд проєкту

**Мета:** Розробка мультимодальної архітектури, яка класифікує швидкість усиновлення за 4 категоріями (від найшвидшого до найповільнішого). Рішення ефективно поєднує методи комп'ютерного зору (CV) та обробки природної мови (NLP).

### Ключові особливості архітектури

* **Мультимодальність:** Використання механізму **Cross-Attention** для глибокої взаємодії між візуальними та текстовими ознаками.
* **Текстовий модуль:** Вилучення семантичних ембеддінгів за допомогою моделі `sentence-transformers/all-MiniLM-L6-v2`.
* **Візуальний модуль:** Застосування переднавченої нейромережі `ResNet50` для аналізу зображень.
* **Автоматизація процесів:** Підбір гіперпараметрів через **Optuna**, автоматичне кешування ознак та система Early Stopping.

> **Важливо:** Для підвищення стабільності та точності прогнозів реалізована підтримка TTA (Test Time Augmentation), що дозволяє покращити метрику на 1-2%.
